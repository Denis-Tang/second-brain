# Second Brain · 架构总结

一套面向多个 AI Agent 的**共用长期记忆系统**的架构总结文档。

## 这是什么

本仓库是第二大脑系统的**架构总结与缺陷评估**，论述范围为：

- **运转机制**：用户与会话 Agent 的实际使用流程、任务绑定与跨窗口交接
- **核心亮点**：多 Agent 协作、工作区交接、知识沉淀、雷区避雷、上下文成本控制、执行层治理
- **真实缺陷**：以系统自身的度量产物与运行日志为依据的缺陷清单与结构性归因

本文档**只描述整体架构**，不涉及任何具体业务项目细节。

## 数据口径

文中所有比例、计数、体积与预算数字，**均来自系统自身度量产物的原值**，未作估算或修饰；涉及机制是否存在的结论，以工具层源码与账本的逐项核查为准。
