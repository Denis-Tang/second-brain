知识与技能不包含全局提示词；token 是已保存正文的粗略估算，并非 API 消耗。曲线只展示本机开始记录后的真实历史。

全局提示词

非空时，所有会话启动都全文加载。只由你编辑，夜间维护不会修改。

直接保存到当前知识库的 知识/全局提示词.md。更换知识库路径后，请先保存设置，再到总观编辑新知识库的提示词。

全部项目

每个项目独立管理名称和工作目录，可持续新增。

项目包含所选目录的全部子目录；嵌套配置时，更具体的目录优先。未配置路径作为独立会话。删除项目仅移除立项和路径绑定，历史资料保留。

新增项目

创建一个独立项目，可关联多个工作目录。

移除路径只解除关联，保留文件和历史记录。修改名称保留原项目资料目录和链接。

删除项目

删除后移除立项和路径绑定，项目卡归档；历史总结、任务、决策及工作目录保留。

选择你的 Vault

保存后自动建立知识库基础目录。前往项目配置添加工作目录，再复制内置提示词接入 Agent。

模型连接

可选择，暂时只支持deepseek。

密钥未配置

密钥只在本机保存，不会回显。填写新密钥后点击保存即可替换。

夜间自动维护

应用运行时，每天按本机时间整理待处理内容。

本机时间

官方 DeepSeek V4.1 Flash（deepseek-flash），非思考模式。每月最多 ¥10；每日最多 3 批，累计输入 30,000 / 输出 30,000 tokens，每批最多输出 10,000 tokens。预算不足保留积压；含用量未知请求的预留费用。

默认关闭，默认时间为 02:00。关闭窗口后仍在托盘运行；退出应用后停止维护；下次启动达到维护时点后补处理积压。
