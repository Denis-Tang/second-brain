初次配置步骤

  1. 选择知识库

    选择保存记忆的文件夹，然后保存设置。已有知识库可以直接使用。

  2. 接入 Agent

    复制内置提示词，交给你使用的 Agent。后续 Agent 复用同一知识库。

  3. 按需添加项目

    在“项目配置”关联工作文件夹，记录项目进度。

可选设置

在“总观”填写全局提示词，让 Agent 记住你的习惯。

在“设置”填写模型密钥并开启夜间维护，自动整理知识。

选择知识库

选择保存记忆的文件夹，已有知识库可以直接使用。

模型连接

用于夜间整理，暂时支持 DeepSeek。

密钥未配置

密钥只在本机保存，不会回显。填写新密钥后点击保存即可替换。

夜间自动维护

应用运行时，每天按本机时间整理待处理内容。

本机时间

使用 DeepSeek V4.1 Flash 整理新增内容。每月最多 10 元，每天最多整理 3 批；超出预算的内容留待后续处理。

默认凌晨 02:00，需手动开启。关闭窗口后可在托盘继续运行；退出程序会停止整理，下次启动再处理积压。
